ClickJacking Community Help 
ClickJacking Community Help is a fictional not-for-profit community and social services organisation created for the COS10026 Web Technology Project. The website connects prospective volunteers with community programs, explains available opportunities and provides an accessible volunteer registration process. 
###
Website pages 
index.html — Home page with organisation information, volunteer pathways, registration steps, a merged-cell table and an Acknowledgement of Country. 
jobs.html — Volunteer position descriptions and requirements. 
apply.html — Volunteer application form with HTML5 validation. 
about.html — Team information, member contributions, first-language quotes, a group photograph and team fun facts. 
###
Main features 

Consistent navigation and footer across all pages 
Responsive layouts created with CSS Grid and Flexbox 
CSS-generated hero background graphic 
Community-volunteering visual content 
HTML5 form controls and validation 
Meaningful tables with accessible headings and captions 
External stylesheet at styles/styles.css 
GitHub Pages deployment 
###
Accessibility 
The website includes: 
semantic HTML elements and a logical heading structure; 
keyboard-accessible skip links; 
visible :focus-visible indicators; 
descriptive alternative text for meaningful images; 
labelled form controls; 
responsive layouts for desktop, tablet and mobile screens; 
reduced-motion support where applicable.
